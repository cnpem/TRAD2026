# Contribuindo

Queremos tornar a contribuição para o **TRAD2026** o mais simples e transparente possível.
Agradecemos seu apoio na melhoria do repositório e dos materiais desse treinamento.

## Como contribuir?

Antes de começar, leia nosso [Código de Conduta](CODE_OF_CONDUCT.md).

Para contribuir com o **TRAD2026**, basta seguir os passos abaixo:

1. Faça um [fork](https://github.com/cnpem/TRAD2026/fork) do repositório no GitHub.

2. Clone o repositório para sua máquina local.

```bash
git clone https://github.com/<seu-usuario>/TRAD2026.git
cd TRAD2026
```

3. Crie uma nova branch para sua feature ou correção de bug.

```bash
git checkout -b minha-branch-de-feature
```

4. Faça suas alterações e commit.

```bash
git add .
git commit -m "Descrição das suas alterações"
```

5. Envie suas alterações para o seu repositório forkado.

```bash
git push origin minha-branch-de-feature
```

6. Crie um pull request para o repositório principal.

7. Aguarde a revisão e feedback da equipe do projeto. Faça as alterações solicitadas, se necessário.

8. Após a aprovação, suas alterações serão mescladas ao repositório principal.
